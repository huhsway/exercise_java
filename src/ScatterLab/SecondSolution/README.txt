종윤이는 1분에 2마리의 치킨을 튀길 수 있는데 X마리의 주문이 들어왔어
근데 너무 많아서 다 튀길 수 없었고 알바를 고용하려고해
알바들은 한 명당 1분에 F마리의 치킨을 튀길 수 있지만, 수당으로 치킨 C마리를 미리 줘야 일을 하겠다고하는 상황이야
알바들을 적절히 고용해서 주문한 X마리의 치킨을 튀기는데 걸리는 최소시간을 반환하는 solution 함수를 작성해줘 (반올림하여 소수점 6번째 자리까지의 값을 반환)

제한
알바 당 인건비(치킨): 1 <= C <= 10000
알바 당 치킨 생산량: 1 <= F <= 100
목표 치킨량: 1 <= X <= 100000

입출력 예
C	F		X		Return
30.0	1.0		2.0		1.0
30.0	2.0		100.0		39.166667
30.5	3.14159	1999.1999	63.968001
500.0	4.0		2000.0	526.190476
